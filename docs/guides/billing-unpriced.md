# 理解未计价调用与费用估算

<!-- markdownlint-configure-file { "MD013": { "tables": false } } -->

[返回使用指南](README.md)

AstrLink 根据上游返回的用量，以及为该次调用选定的官方价格快照，估算按 API 价格折算的费用。**这项估算不等于提供商实际扣费，也不能替代账单。**

## 用量不完整时如何折算

用量缺少某项明细时，AstrLink 按下表折算上游已报告的用量：

| 情况                               | 如何折算                                 |
| ---------------------------------- | ---------------------------------------- |
| 流式响应中断，只拿到部分用量       | 按已报告的用量折算，可能低于实际扣费     |
| 调用失败或被取消，上游没有报告用量 | 记为 $0                                  |
| 缓存写入没有区分 5 分钟和 1 小时   | 全部按 5 分钟缓存写入价格折算            |
| 没有音频用量明细                   | 全部按文本价格折算                       |
| 同时有缓存命中和音频用量           | 缓存命中按文本缓存价格折算               |
| 请求没有说明是否开启思考           | 按未开启思考的价格折算                   |
| 某项用量大于总量                   | 按总量截断，例如缓存命中最多等于输入总量 |

## 哪些调用仍然未计价

以下调用显示为“未计价”或“部分未计价”。金额合计不含它们的费用，提供商可能已经扣费：

- 官方价格目录里找不到该模型的价格。价格目录更新后会自动补算。
- 调用成功，但上游没有返回用量，例如 OpenAI Chat 流式请求没有开启
  `stream_options.include_usage`。提供商按实际用量扣费，AstrLink 无法得知金额。

## 旧记录会自动补算

启动时以及之后每隔 5 分钟，AstrLink 会按上面的规则，用调用原有的价格和用量快照重新折算早期版本留下的未计价记录，并计入重新计价数量（`revalued`）。已经计价的金额和记录所属账号保持原样。

失败或被取消、没有用量的旧记录要靠请求日志确认调用结果。请求日志已经删除的记录继续显示为未计价。核对实际支出时，请以提供商账单为准。
